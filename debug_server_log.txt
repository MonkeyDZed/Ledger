## Structure de la table pieces

CREATE TABLE pieces (
    id TEXT PRIMARY KEY,
    supplier_id TEXT NOT NULL,
    date TEXT NOT NULL,
    type TEXT NOT NULL,
    total_piece REAL NOT NULL,
    montant_paye REAL NOT NULL,
    reste REAL NOT NULL,
    description TEXT,
    payment_method TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    FOREIGN KEY (supplier_id) REFERENCES suppliers (id) ON DELETE CASCADE
);

## Structure de la table versements

Il n'y a pas de table "versements" séparée. Les versements sont gérés dans la table "pieces" avec le type 'VERSEMENT'.
