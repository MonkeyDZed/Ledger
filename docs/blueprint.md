# **App Name**: LedgerSync Local

## Core Features:

- Supplier CRUD: Create, read, update, and delete suppliers including their name, province (wilaya), contact information, NIF, bank information, initial balance, and notes.
- Record entry: Quickly add records with the date, type (delivery note/invoice), total amount, and amount paid; the outstanding balance is calculated automatically.
- Supplier statement: Generate supplier statements that list all records with calculated totals.
- Overall status: Generate a table of all suppliers with the total outstanding balance (including the initial balance).
- Report Export: Export reports to CSV and PDF formats.
- Search and Filtering: Quickly find specific entries or categories using keyword or filters. Sort data by date, type, or amount.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust, stability, and professionalism, suitable for financial management.
- Background color: Light gray (#F5F5F5), to maintain focus and legibility.
- Accent color: Vibrant purple (#7E57C2), which is analogous to the primary blue but distinct, for interactive elements.
- Body and headline font: 'Inter', a sans-serif font that will lend a modern, objective, neutral feel.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use minimalist icons for navigation and key actions.
- Responsive layout optimized for keyboard navigation to ensure ease of use.
